# Investigacion historica

Los informes academicos y matrices AS-IS/TO-BE se conservan como evidencia historica en `docs/08-otros/investigacion/`. No deben usarse como inventario vigente sin contrastarlos con `src/`.

## Criterio de lectura

- El informe academico explica la motivacion de la reingenieria.
- La matriz de evidencias contiene estados de migracion declarados en una fecha anterior.
- `architecture/module-inventory.md`, `architecture/system-overview.md` y `development/test-inventory.md` son la referencia actual del codigo observado.
- Cuando exista conflicto, prevalecen el codigo y las pruebas actuales; la diferencia debe registrarse como deuda documental.
