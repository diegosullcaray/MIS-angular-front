# Diagramas

Los diagramas deben explicar limites, flujo de datos y autorizacion. El modelo detallado de accesos se resume en [Access model](../api-contracts/access-model.md).

Convenciones:

- Mostrar la fuente de verdad y el sentido del flujo.
- Separar datos de presentacion de decisiones de autorizacion.
- Versionar diagramas junto al contrato o ADR que explican.
