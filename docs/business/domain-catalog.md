# Catalogo de dominios

| Dominio | Responsabilidad funcional | Fuente principal observada |
|---|---|---|
| Actividades | Destino de credito y corresponsales | `ActividadesService`, Ant `app` |
| Analista | Principal, listas, leads, becas y reportes analiticos | servicios de modulo y reportes |
| Categorizacion | Categorizacion y seleccion de sectorista | `CategorizacionService` |
| Dashboard | Reportes integrados y Power BI | `DashboardService`, Ant `app` |
| ESG | Metricas y categorias de sostenibilidad | `FrameworkEsgService`, Ant `app` |
| Herramientas | Base negativa y consultas de riesgo | `BaseNegativaService`, Ant `app` |
| Incentivos | Configuracion, calculo y detalle de incentivos | servicios y utils locales |
| Kaypacha/Ranking | Categorias, mapas, ranking y recorridos guiados | `KaypachaService`, MapLibre |
| Presupuesto | Lineas, responsables, verificaciones y resumenes | `PresupuestoService`, Ant `app` |
| Reportes | Reporterias operativas, comerciales, cartera y sostenibilidad | `ModReportesService`, `ModRep2Service` |

El catalogo describe limites del frontend. La definicion oficial del dato, su calidad y su responsable deben confirmarse con negocio y backend.
