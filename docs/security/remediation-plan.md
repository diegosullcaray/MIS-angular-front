# Plan de remediacion

1. Validar autorizacion server-side para cada operacion.
2. Rotar y retirar secretos del bundle publico.
3. Sustituir el esquema criptografico legado por transporte seguro y autenticado.
4. Adoptar CSP y Authorization Code Flow con PKCE.
5. Repetir pentest y registrar evidencia en `reports/`.

Cada fase requiere responsable, fecha, prueba de aceptacion y decision de rollback.
