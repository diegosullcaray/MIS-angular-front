# Guia de desarrollo

- Seguir la arquitectura standalone, zoneless y basada en senales.
- Separar constantes, modelos, mapeos puros y servicios de transporte.
- Usar nombres de dominio del glosario y conservar el nombre original del backend cuando sea parte del contrato.
- Actualizar documentacion y pruebas en el mismo cambio.
- Las ramas y commits deben indicar el modulo o contrato afectado.
