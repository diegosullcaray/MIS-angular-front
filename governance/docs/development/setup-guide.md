# Setup local

1. Requiere Node compatible con `package.json`.
2. Ejecutar `npm install`.
3. Ejecutar `npm start`.
4. Ejecutar `npm test` para la suite configurada.
5. No colocar secretos reales en el frontend ni en archivos versionados.

Las variables y reemplazos de entorno se describen en `src/environments/` y deben validarse con el equipo de backend.
