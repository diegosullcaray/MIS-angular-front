# Diagramas

Los diagramas deben explicar limites, flujo de datos y autorizacion. El modelo de acceso se resume en [Access model](../api-contracts/access-model.md).

Convenciones:

- Mostrar la fuente de verdad y el sentido del flujo.
- Separar datos de presentacion de decisiones de autorizacion.
- Versionar diagramas junto al contrato o ADR que explican.
- Usar Mermaid para flujos y secuencias; no duplicar diagramas que ya esten explicados en `data-flow.md`.
