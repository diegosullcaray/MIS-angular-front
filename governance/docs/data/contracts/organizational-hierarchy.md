# Organizational hierarchy

Los reportes se consultan sobre un nodo organizativo. El contrato conserva `cod_jer`, niveles, `tip_cod`, `cod_rel`, `cod_rels` y etiquetas de nivel.

La fecha de corte pertenece al perfil del usuario y debe incluirse con el nombre y formato que exige cada motor. Un cambio de nivel debe limpiar los descendientes seleccionados y volver a consultar el reporte.
